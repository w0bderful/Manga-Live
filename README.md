# Manga OCR Translator

**화면의 일본어를 읽어 한국어 번역을 같은 위치에 표시하는 Windows용 만화 번역기**입니다. 브라우저나 이미지 뷰어에 열린 만화에서 원하는 부분을 드래그해 번역하거나, 지정한 영역의 화면 변화를 계속 감시할 수 있습니다.

프로그램 창 이름은 **Manga Live · 일본어 → 한국어**입니다.

> **AI 창작물 안내**  
> 이 프로그램은 사용자의 요청을 바탕으로 AI가 코드를 작성한 창작물입니다. 이 README도 AI가 작성했습니다. 사용된 외부 라이브러리와 사전 학습 모델은 각 제작자의 별도 저작물입니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 드래그 번역 | 선택한 영역을 한 번 캡처하고 바로 번역 |
| 자동 번역 | 지정한 영역의 화면 변화 감지 및 재처리 |
| 번역 오버레이 | 말풍선별 번역이 끝나는 즉시 원문 위치에 표시 |
| 스크롤 추적 | 자동 번역 중 화면 이동에 맞춰 기존 번역 위치 추적 |
| 사용자 지정 전역 단축키 | 다른 앱을 보고 있을 때도 영역 선택·번역·시작·재번역 실행 |
| OCR 모드 선택 | Manga OCR, EasyOCR, OpenCV 기반 감지 |
| CPU / GPU 선택 | 로컬 OCR을 CPU 또는 NVIDIA CUDA GPU에서 실행 |
| 번역 서비스 선택 | Luna(Kie API), DeepL Free, 주소를 직접 지정하는 OpenAI 호환 API |
| 최상단 고정 | 설정 창을 다른 앱 위에 표시하거나 고정 해제 |

## 빠른 시작

### 1. 준비하기

- Windows PC와 Python이 필요합니다. `python --version` 명령이 실행되어야 합니다.
- 코드에는 Python 3.11 이상의 기능이 사용됩니다. 실제 설치 가능한 Python 버전은 의존성 패키지의 지원 범위에도 영향을 받습니다.
- 패키지와 OCR 모델을 다운로드할 인터넷 연결이 필요합니다.
- 번역에는 선택한 서비스에 접근할 수 있어야 합니다. 외부 서비스는 API 키와 인터넷 연결이 필요하며 이용 요금이 발생할 수 있습니다. 인증이 없는 로컬 OpenAI 호환 서버는 API 키 없이 사용할 수 있습니다.

현재 의존성 목록은 CUDA 13.0용 `torch==2.14.0+cu130`과 `torchvision==0.29.0+cu130`을 지정합니다. 프로그램은 **GPU 모드(NVIDIA CUDA)**가 선택된 상태로 시작하며, 초기 OCR 작업도 GPU로 실행합니다. 호환되는 NVIDIA GPU와 드라이버가 필요합니다. GPU를 사용할 수 없는 환경에서는 **CPU 모드**를 선택하고 **설정 적용**을 누르세요. 설치 스크립트는 CPU 전용 패키지를 자동 선택하지 않습니다.

### 2. 설치하고 실행하기

저장소를 다운로드하거나 복제한 뒤 프로젝트 폴더에서 실행하세요.

| 상황 | 실행 파일 | 수행 작업 |
| --- | --- | --- |
| 처음 사용 | `setup.bat` | `.venv` 생성 → 가상환경 활성화 → 의존성 설치 → 프로그램 실행 |
| 설치 완료 후 | `run.bat` | 기존 가상환경 활성화 → 프로그램 실행 |

`setup.bat`은 설치가 성공하면 프로그램까지 실행합니다. 다음 실행부터는 `run.bat`을 사용하면 됩니다. 가상환경이 없으면 `run.bat`이 먼저 설치하라는 안내를 표시합니다.

PowerShell에서 직접 실행하려면 다음 명령을 사용하세요. 가상환경의 Python을 직접 지정하므로 활성화 명령은 생략할 수 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

### 3. 번역 설정하기

1. 만화를 브라우저나 이미지 뷰어에 표시합니다.
2. 프로그램에서 **대상 모니터**, **CPU/GPU**, **OCR 모드**, **번역 서비스**를 선택합니다.
3. 선택한 서비스의 API 키를 입력하고 **설정 적용**을 누릅니다. OpenAI 호환 API는 주소·키 입력 후 **모델 불러오기**를 눌러 모델을 선택합니다.
4. 설정 적용이 끝나면 아래 두 방식 중 하나로 번역합니다.

선택한 번역 서비스는 자동 저장됩니다. 프로그램을 다시 실행하면 마지막으로 선택한 **Luna / DeepL Free / OpenAI 호환 API**와 해당 설정을 복원합니다. 저장된 선택이 없으면 Luna로 시작합니다.

OCR 모델은 **첫 번역 요청 시** 불러옵니다. 저장된 모델이 없으면 다운로드하므로 첫 처리는 오래 걸릴 수 있습니다. 화면에 준비 완료가 표시되어도 API 키의 유효성이나 사용 한도가 검증된 것은 아니며, 실제 요청에서 오류가 표시될 수 있습니다.

### 설정 창 최상단 고정

창 오른쪽 위의 **최상단 고정**을 체크하면 설정 창을 다른 앱보다 위에 표시합니다. 체크를 해제하면 일반 창처럼 사용할 수 있습니다. 시작할 때는 기본으로 체크되어 있으며, 번역 오버레이는 계속 원문 위에 표시됩니다.

## 번역 방법

### 드래그한 부분을 한 번 번역하기

1. **드래그 번역** 버튼 또는 기본 단축키 `Ctrl+Alt+2`를 누릅니다.
2. 번역할 영역을 마우스로 드래그한 뒤 놓습니다.
3. 선택 영역을 한 번 캡처해 자동으로 번역합니다. 별도의 시작 조작은 필요하지 않습니다.

번역 결과는 화면에 남습니다. 이 모드에서는 화면 변화나 스크롤을 추적하지 않습니다.

- 같은 위치의 현재 화면을 새로 읽기: **다시 번역**
- 다른 영역 선택: **드래그 번역**
- 영역 선택 취소: `Esc`
- 처리 중 중단: **취소**
- 완료 후 같은 영역을 계속 감시: **시작**

### 선택 영역을 계속 자동 번역하기

1. **영역 선택** 버튼 또는 `Ctrl+Alt+1`을 누릅니다.
2. 감시할 부분을 드래그합니다.
3. **시작** 버튼 또는 `Ctrl+Alt+3`을 누릅니다.

선택 영역의 변화가 잠시 멈추면 OCR과 번역을 수행합니다. 말풍선별로 결과를 표시하고 스크롤 시 기존 번역의 위치를 추적합니다. **일시정지**를 누르면 감시를 멈추고 표시된 번역을 지웁니다.

**다시 번역**은 현재 결과를 초기화합니다. 자동 번역이 실행 중이면 다음 캡처부터 재처리하고, 일시정지 중이면 **시작**을 눌러야 처리됩니다. 동일 이미지나 문장의 결과는 메모리 캐시에서 재사용할 수 있으므로 매번 새로운 API 요청이 발생하는 것은 아닙니다.

### 말풍선 하나만 읽기

말풍선 하나를 좁게 선택하고 **선택 영역 전체가 말풍선 하나 (자동 감지 생략)**를 켜세요. 자동으로 글자 영역을 찾는 과정을 생략하고 선택 영역 전체를 OCR에 전달합니다.

CPU/GPU, OCR 방식, API 키 등 설정을 바꾼 뒤에는 **설정 적용**을 완료하고 다시 번역하세요. 설정 변경으로 진행 중인 작업이나 표시 결과가 초기화될 수 있습니다.

드래그 번역이 설정 적용을 기다리는 중이라면 캡처한 이미지를 유지하고, 적용 완료 후 자동으로 번역합니다. 대기 중 **취소**를 누르면 자동으로 재개하지 않습니다.

## 단축키 설정

프로그램의 **단축키 설정**을 열고, 원하는 기능의 입력칸을 클릭한 다음 키 조합을 누르세요. **저장**하면 즉시 적용되고 다음 실행에도 복원됩니다.

| 기능 | 기본 단축키 |
| --- | --- |
| 영역 선택 | `Ctrl+Alt+1` |
| 드래그 번역 | `Ctrl+Alt+2` |
| 시작 / 일시정지 / 드래그 번역 처리 중 취소 | `Ctrl+Alt+3` |
| 다시 번역 | `Ctrl+Alt+4` |

- 프로그램이 실행 중이면 다른 앱에 포커스가 있어도 작동합니다.
- 영문·숫자·방향/이동 키 등은 `Ctrl`, `Alt`, `Shift`, `Win` 중 하나 이상과 조합합니다. F키는 단독으로도 지정할 수 있습니다.
- F12와 숫자 패드 키는 지정할 수 없습니다. Windows 예약 조합이나 다른 앱이 사용 중인 키도 등록되지 않을 수 있습니다.
- 중복 지정이나 등록 실패는 설정창에서 안내합니다. 시작 시 등록 실패는 프로그램 하단에 표시합니다.
- **해제**는 해당 기능의 단축키를 비우고, **기본값 불러오기**는 위 표의 조합으로 되돌립니다. 변경 후 저장하세요.
- 설정창에서 키를 입력하는 동안에는 전역 단축키를 일시 해제합니다. **취소**하면 기존 설정으로 복원합니다.
- 영역 선택 중에는 단축키를 무시합니다. 선택을 취소하려면 `Esc`를 사용하세요. 번역 설정 적용 중에도 단축키 실행을 막습니다.

단축키는 버튼과 같은 기능을 실행합니다. API 키와 번역 영역 등 필요한 준비 조건도 같습니다.

## OCR과 번역 서비스

### OCR: 이미지 속 일본어 읽기

| OCR 모드 | 영역 감지 | 글자 인식 |
| --- | --- | --- |
| Manga OCR — 기본값 | EasyOCR | Manga OCR |
| EasyOCR | EasyOCR | EasyOCR |
| OpenCV | OpenCV, 감지가 부족한 경우 EasyOCR로 보완 | Manga OCR |

OCR은 로컬에서 처리합니다. CPU/GPU 선택은 OCR 모델에 적용되며, OpenCV 영역 감지는 CPU에서 실행됩니다.

감지 해상도는 **원본 해상도**가 기본값입니다. **빠른 감지(960)**, **균형 감지(1280)**, **정밀 감지(1920)**도 선택할 수 있습니다. 큰 영역이나 높은 해상도에서는 시간과 메모리가 더 필요할 수 있습니다. 작은 글씨를 놓치면 원본/정밀 감지 또는 말풍선 하나 모드를 사용해 보세요.

### 번역: 인식한 대사를 한국어로 변환

| 번역 서비스 | 필요한 API 키 | 현재 코드의 설정 |
| --- | --- | --- |
| Luna (Kie API) — 최초 실행 기본값 | Kie API 키 | `api.kie.ai`, 모델 식별자 `gpt-5-6-luna` |
| DeepL Free | DeepL API 키 | 일본어 `JA` → 한국어 `KO` |
| OpenAI 호환 API | 지정한 서버의 키 (인증 없는 서버는 생략) | 주소 직접 입력·서버 모델 목록에서 선택, Chat Completions 방식 |

DeepL은 키가 `:fx`로 끝나면 Free API 호스트를, 그 외에는 Pro API 호스트를 사용하도록 구현되어 있습니다. 서비스에서 실제로 사용할 수 있는 기능은 해당 계정과 API 지원 상태에 따라 달라집니다.

### OpenAI 호환 API 사용하기

1. 번역 서비스에서 **OpenAI 호환 API (주소 직접 입력)**를 선택합니다.
2. **API 주소**에 서버의 기본 주소 또는 전체 Chat Completions 주소를 입력합니다.
   - 기본 주소 예: `https://api.openai.com/v1`, `http://localhost:1234/v1`
   - 전체 주소 예: `http://localhost:1234/v1/chat/completions`
3. 해당 서버의 **API 키**를 입력합니다. 인증이 없는 로컬 서버는 키를 비워도 됩니다.
4. **모델 불러오기**를 누르고, **모델 선택** 목록에서 사용할 모델을 고릅니다.
5. **설정 적용**을 누릅니다. 주소·키·선택한 모델은 자동 저장되므로 다음 실행에서 복원됩니다.

모델 목록은 입력한 주소·키로 [모델 조회 API (`GET /models`)](https://developers.openai.com/api/reference/python/resources/models/methods/list)를 호출해 불러옵니다. 조회 중에도 창을 사용할 수 있으며, 오류가 나면 모델 선택 아래에 원인을 표시합니다. 조회 자체로 번역 요청을 보내지는 않습니다.

주소나 키를 바꾸면 이전 목록과 선택을 지우므로 다시 불러와 선택하세요. 같은 서버의 목록을 새로 불러올 때는 기존 모델이 목록에 있으면 선택을 유지합니다. 기존 모델이 사라졌거나 목록이 비어 있으면 새 모델을 선택해야 합니다. 모델 이름을 직접 입력하는 기능은 없습니다.

서버가 반환하는 목록에는 번역용 Chat Completions를 지원하지 않는 모델도 포함될 수 있습니다. 모델 목록 조회와 실제 번역 가능 여부는 별개이며, Chat Completions를 지원하는 모델을 선택해야 합니다.

기본 주소에는 `/chat/completions`를 붙여 요청합니다. 경로가 없는 서버 주소는 `/v1/chat/completions`를 사용하고, 전체 주소를 입력하면 중복으로 붙이지 않습니다. HTTP·HTTPS와 사용자 지정 포트를 지원합니다.

요청은 `model`, `messages`, `stream: false`를 사용하는 [Chat Completions 규격](https://developers.openai.com/api/reference/python/resources/chat/subresources/completions/methods/create)을 따릅니다. Responses API만 제공하는 서버는 이 모드로 사용할 수 없습니다. 모델과 번역 지원 여부는 연결한 서버에 따라 달라집니다.

## 화면 처리와 데이터 저장

```text
영역 선택 → 화면 캡처 → 로컬 OCR → 텍스트를 번역 API로 전송 → 한국어 표시
```

### 전송하는 정보

**인식한 대사를 선택한 번역 서비스(Kie, DeepL 또는 직접 지정한 OpenAI 호환 서버)로 전송합니다.** 앱의 번역 요청에는 화면 이미지가 포함되지 않습니다. OCR 모델 다운로드와 번역 API 이용에는 네트워크 연결이 발생합니다.

### API 설정 저장

입력한 키와 OpenAI 호환 API의 주소·모델 이름은 **`api-keys.json`에 평문으로 자동 저장**됩니다. 입력 변경 후 약 0.5초 뒤와 설정 적용 시 저장합니다. 저장과 번역에 적용하는 동작은 별개이므로, 입력을 바꾼 뒤에는 **설정 적용**을 누르세요. 이 파일에는 실제 인증 정보가 있으므로 공유하지 마세요.

API 키 파일이 손상되어도 설정 화면은 열립니다. 키를 다시 입력해 저장하면 손상된 원본을 **`api-key-backups/`에 백업**하고 새 설정을 저장합니다. 백업에도 인증 정보가 포함될 수 있으며 Git 추적에서 제외됩니다.

파일의 `kie_api_key`, `deepl_api_key`, `openai_api_key` 항목이 우선하며, 해당 항목이 없으면 각각 `KIE_API_KEY`, `DEEPL_API_KEY`, `OPENAI_API_KEY` 환경 변수를 읽습니다. 호환 서버의 주소와 모델은 `openai_base_url`, `openai_model`에 저장합니다. `.env`를 자동 로딩하는 기능은 없습니다. UI에서 설정을 저장하면 환경 변수에서 불러온 키도 파일에 저장될 수 있습니다.

마지막으로 선택한 번역 서비스는 같은 파일의 `translation_provider`에 저장합니다. API 키나 모델 설정을 아직 완료하지 않았어도 서비스 선택은 기억합니다.

### 생성되는 파일

| 경로 | 내용 | Git 추적 |
| --- | --- | --- |
| `.venv/` | Python 가상환경과 설치 패키지 | 제외 |
| `.models/` | 다운로드한 OCR 모델 | 제외 |

외부에서 `HF_HOME`을 지정한 경우 Hugging Face 모델 캐시 위치가 달라질 수 있습니다. `시작방법.txt`는 저장소에 포함된 실행 안내 메모입니다.

### 오버레이와 화면공유

번역은 별도 표시창으로 화면 위에 그려집니다. 마우스 입력은 아래 앱으로 통과합니다. 번역기 창이 원문을 가리면 Windows 창 캡처 기능으로 아래 내용을 복원해 읽습니다.

캡처는 별도 보조 프로세스에서 실행합니다. 5초 동안 응답이 없으면 해당 작업을 종료하며, **다시 번역**하거나 영역을 새로 선택하면 보조 프로세스를 다시 시작합니다. 자동 번역이 중단된 경우에는 **시작**을 눌러 재개하세요.

프로그램에는 Discord에서 **Manga Live · 일본어 → 한국어** 창을 선택하라는 공유 안내가 있습니다. 실제 공유 결과와 가려진 영역의 캡처 가능 여부는 대상 앱과 캡처 방식에 따라 달라집니다.

## 문제 해결

| 증상 | 조치 |
| --- | --- |
| `python` 명령을 찾을 수 없음 | Python 설치와 PATH 설정을 확인하고 터미널을 다시 엽니다. |
| 패키지 설치 실패 | BAT 창의 오류와 Python·PyTorch 지원 버전을 확인합니다. |
| 첫 번역이 오래 걸림 | 상태창에서 OCR 모델 다운로드·로딩 여부를 확인합니다. |
| API 키 오류 또는 사용 한도 오류 | 선택한 서비스의 키와 이용 한도를 확인하고 설정을 적용합니다. |
| OpenAI 호환 API 연결 실패·404 | 서버 실행 상태, 주소, 포트, 모델 이름 및 Chat Completions 지원 여부를 확인합니다. |
| 모델 목록 조회 실패·목록 없음 | API 주소·키와 서버의 `/models` 지원 여부를 확인한 뒤 **모델 불러오기**로 재시도합니다. |
| API 키 파일을 읽지 못함 | 키를 다시 입력하고 설정을 적용합니다. 손상된 원본은 저장 시 `api-key-backups/`에 보관됩니다. |
| 영역 좌표 조회 실패 | 대상 창과 모니터 상태를 확인한 뒤 영역을 다시 선택합니다. |
| 로그 파일을 열 수 없음 | 파일 기록 없이 실행되며 창에 안내가 표시됩니다. `manga-live.log`의 권한과 잠금 상태를 확인합니다. |
| 단축키가 동작하지 않음 | 하단 등록 오류, 다른 앱과의 충돌, 설정창/영역 선택 여부를 확인합니다. |
| 글자를 놓치거나 잘못 읽음 | 영역을 좁히고 OCR 방식·감지 해상도·말풍선 하나 옵션을 변경합니다. |
| GPU 사용 불가 | CPU 모드로 설정을 적용하거나 NVIDIA 드라이버·CUDA용 PyTorch 환경을 확인합니다. |
| 아래 창 캡처 실패·응답 지연 | 대상 앱 상태를 확인하고 번역기 창을 영역 밖으로 옮긴 뒤 재시도합니다. |
| 번역 위치가 어긋남 | 화면 이동을 멈추고 **다시 번역**을 누릅니다. |
| API 응답 대기·연결 실패 | 인터넷과 서비스 상태를 확인하고 **다시 번역**으로 재시도합니다. |

자세한 오류는 프로그램 상태창과 `manga-live.log`에서 확인할 수 있습니다.

## 현재 지원 범위

- Windows 전용이며 번역 방향은 **일본어 → 한국어**로 고정되어 있습니다.
- 번역 정확도는 OCR 결과와 번역 서비스에 따라 달라집니다. 효과음, 특수 글씨체, 세로쓰기, 작은 글자, 복잡한 배경에서는 오류가 발생할 수 있습니다.
- 말풍선 단위로 처리하므로 장면 전체의 문맥이나 인물의 말투를 충분히 반영하지 못할 수 있습니다.
- 스크롤 추적은 항상 성공하지 않으며, 처리 시간도 하드웨어·선택 영역·API 응답 속도에 따라 달라집니다.
- 취소하면 결과 반영을 중단하지만, 이미 전송된 API 요청이나 실행 중인 모델 연산이 즉시 중단되는 것은 아닙니다.
- 원본 이미지 편집, 번역 이미지 저장, 만화 파일 일괄 변환 기능은 없습니다.

| `setup.bat` / `run.bat` | 최초 설치·실행 / 설치 후 실행 |
| `tests/` | 단축키, 캡처 복구, API 설정 저장·복구, 드래그 번역, 최상단 고정 및 호환 API 회귀 테스트 |

회귀 테스트는 프로젝트 폴더에서 다음과 같이 실행합니다. 실제 번역 API는 호출하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
