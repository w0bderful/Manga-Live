# Manga OCR Translator

Windows 화면에 표시된 일본어를 읽고, 한국어 번역을 글자 위치에 겹쳐 보여주는 프로그램입니다. 만화가 열린 브라우저나 이미지 뷰어에서 번역할 부분을 드래그해 사용할 수 있습니다. 프로그램 창 이름은 **Manga Live · 일본어 → 한국어**입니다.

> **AI 창작물 안내**  
> 이 프로젝트는 사용자의 요청을 바탕으로 AI가 코드를 작성한 창작물이며, 이 README도 AI가 작성했습니다. 외부 라이브러리와 사전 학습 모델은 각 제작자의 별도 저작물입니다. 인식 및 번역 결과에는 오류가 있을 수 있습니다.

## 어떻게 작동하나요?

```text
화면 영역 선택
  → 선택 영역 캡처
  → 로컬 OCR로 일본어 인식
  → 인식한 대사를 Kie 또는 DeepL API에 전송
  → 한국어 번역을 원래 글자 위치에 표시
```

**OCR은 로컬에서, 번역은 외부 API에서 처리합니다.** 앱의 번역 요청에는 인식한 텍스트가 포함되며 화면 이미지는 포함되지 않습니다. 번역에는 인터넷 연결과 선택한 서비스의 API 키가 필요하며, 서비스 이용 요금이 발생할 수 있습니다.

### 화면 캡처와 결과 표시

- 선택한 모니터의 지정 영역만 처리합니다.
- 번역기 창이나 번역 표시가 원문을 가릴 때는 Windows의 창 캡처 기능으로 아래 창의 내용을 읽어 복원합니다. 대상 앱이 창 캡처에 응답하지 않으면 오류가 발생할 수 있습니다.
- 말풍선별 처리가 끝나는 즉시 번역을 표시합니다. 번역 표시창은 마우스 입력을 통과시켜 원래 앱을 조작할 수 있습니다.
- 번역은 화면 위에 표시되며, 원본 이미지 파일을 수정하거나 번역된 파일로 저장하지 않습니다.

## 주요 기능

### 드래그 번역 — 한 번만 번역

**드래그 번역**을 누르고 영역을 드래그한 뒤 마우스를 놓으면, 선택 영역을 한 번 캡처해 번역합니다. 별도로 시작 버튼을 누를 필요가 없습니다.

결과는 화면에 남으며, 이 모드에서는 화면 변화와 스크롤을 추적하지 않습니다. **다시 번역**을 누르면 같은 위치의 현재 화면을 새로 캡처합니다. 다른 영역을 읽으려면 **드래그 번역**을 다시 누르세요. 영역 선택 중 `Esc`로 취소하거나, 처리 중 **취소**를 누를 수 있습니다.

### 자동 번역 — 화면 변화 감시

**영역 선택 → 드래그 → 시작** 순서로 사용합니다. 선택 영역의 변화를 감시하며 화면이 잠시 안정되면 OCR과 번역을 수행합니다. 스크롤 시 기존 번역 위치를 추적하고, 반복되는 이미지와 문장의 결과는 메모리 캐시에서 재사용합니다.

**일시정지**로 감시를 멈추고 **다시 번역**으로 결과를 새로 처리할 수 있습니다. 드래그 번역 완료 후 **시작**을 눌러 같은 영역의 자동 번역으로 전환할 수도 있습니다.

### 사용자 지정 단축키

**단축키 설정**에서 각 입력칸을 클릭하고 원하는 키 조합을 누른 뒤 **저장**을 누르세요. 프로그램이 실행 중이면 다른 앱에 포커스가 있어도 작동합니다.

| 기능 | 기본 단축키 |
| --- | --- |
| 영역 선택 | `Ctrl+Alt+1` |
| 드래그 번역 | `Ctrl+Alt+2` |
| 시작 / 일시정지 / 처리 중 취소 | `Ctrl+Alt+3` |
| 다시 번역 | `Ctrl+Alt+4` |

영문·숫자·방향/이동 키와 Ctrl, Alt, Shift, Win 조합을 지정할 수 있고, F키는 단독으로도 사용할 수 있습니다. F12와 Windows가 예약했거나 다른 앱이 사용 중인 조합은 등록되지 않을 수 있습니다. 중복되거나 등록할 수 없는 키는 저장 시 안내합니다. **해제**로 개별 단축키를 끄거나 **기본값 불러오기**로 초기 조합을 선택할 수 있습니다.

설정은 `hotkeys.json`에 저장해 다음 실행에 복원하며 Git에서는 제외합니다. 설정창을 열어 키를 입력하는 동안 단축키를 일시 해제합니다. 영역을 드래그하는 동안에는 중복 실행을 막기 위해 단축키를 무시하며 `Esc`로 선택을 취소합니다. API 키 등 번역 준비 조건은 버튼 실행과 같습니다.

### OCR 모드

OCR은 이미지 속 글자를 텍스트로 읽는 기능입니다.

| 모드 | 글자 영역 감지 | 글자 인식 |
| --- | --- | --- |
| Manga OCR — 기본값 | EasyOCR | Manga OCR |
| EasyOCR | EasyOCR | EasyOCR |
| OpenCV | OpenCV, 감지가 부족한 경우 EasyOCR로 보완 | Manga OCR |

- **CPU / GPU**: 로컬 OCR 모델을 CPU 또는 NVIDIA CUDA GPU에서 실행합니다. OpenCV 감지는 CPU에서 실행됩니다. 이 선택은 외부 번역 API의 처리 장치를 바꾸지 않습니다.
- **말풍선 하나**: 선택 영역 전체를 하나의 글자 영역으로 취급해 자동 감지를 생략합니다.
- **감지 해상도**: 기본값은 원본 해상도이며, 빠른 감지(960), 균형 감지(1280), 정밀 감지(1920)를 선택할 수 있습니다. 큰 영역이나 높은 감지 해상도는 처리 시간과 메모리 사용량을 늘릴 수 있습니다.

### 번역 서비스

| 앱에서 선택하는 항목 | 필요한 키 | 현재 코드의 요청 대상 |
| --- | --- | --- |
| Luna (Kie API) — 기본값 | Kie API 키 | `api.kie.ai/codex/v1/responses`, 모델 식별자 `gpt-5-6-luna` |
| DeepL API | DeepL API 키 | `/v2/translate`, 일본어 `JA` → 한국어 `KO` |

DeepL 키가 `:fx`로 끝나면 코드에서 `api-free.deepl.com`을, 그 외에는 `api.deepl.com`을 사용합니다. 위 표는 현재 코드의 설정이며, 서비스의 모델 제공 여부나 계정의 사용 가능 범위를 보장하지 않습니다.

## 설치 및 실행

### 준비 사항

- Windows 환경
- Python 3.11 이상: 코드에서 `asyncio.Runner`를 사용합니다. 실제 설치 가능 버전은 의존성 패키지 지원 범위에도 영향을 받습니다.
- 패키지 및 OCR 모델 다운로드를 위한 인터넷 연결
- Kie 또는 DeepL API 키
- GPU 모드를 사용하려면 CUDA를 사용할 수 있는 NVIDIA GPU와 드라이버

현재 `requirements.txt`는 CUDA 13.0용 `torch==2.14.0+cu130`, `torchvision==0.29.0+cu130`을 지정합니다. 앱의 기본 실행 모드는 CPU이지만 설치 스크립트가 CPU 전용 패키지를 자동 선택하지는 않습니다.

### 배치 파일로 실행

1. 저장소를 다운로드하거나 복제합니다.
2. 프로젝트 폴더의 **`setup.bat`**을 실행합니다. `.venv` 가상환경을 만들고 의존성을 설치합니다. Windows Python 런처인 `py` 명령이 필요합니다.
3. 설치가 끝나면 **`run.bat`**을 실행합니다.
4. 번역 서비스를 선택하고 해당 API 키를 입력한 뒤 **설정 적용**을 누릅니다.
5. OCR 모델은 첫 번역 요청 시 불러옵니다. 모델이 없으면 다운로드하므로 첫 처리는 오래 걸릴 수 있습니다.

### PowerShell에서 직접 실행

프로젝트 폴더에서 다음 명령을 실행합니다. 가상환경 활성화 없이도 해당 환경의 Python을 직접 사용할 수 있습니다.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 사용 순서

1. 번역할 일본어 만화를 브라우저나 이미지 뷰어에 표시합니다.
2. 프로그램에서 대상 모니터, CPU/GPU, OCR 모드, 번역 서비스를 선택합니다.
3. 서비스에 맞는 API 키를 입력하고 **설정 적용**을 누릅니다.
4. 한 번 번역하려면 **드래그 번역**, 계속 감시하려면 **영역 선택** 후 **시작**을 사용합니다.
5. 말풍선 하나만 읽을 때는 **선택 영역 전체가 말풍선 하나**를 켜 보세요.
6. 창을 닫으면 프로그램이 종료됩니다.

서비스나 API 키를 바꾼 경우 설정 적용을 완료한 뒤 번역을 시작하세요. 설정 변경 중 진행하던 작업은 중단될 수 있으므로, 변경 후 필요하면 영역을 다시 선택하거나 **다시 번역**을 누르세요.

## API 키와 로컬 데이터

입력한 API 키는 프로젝트 폴더의 **`api-keys.json`에 평문으로 자동 저장**됩니다. 파일을 공유하지 마세요. UI에서 입력을 바꾼 뒤 약 0.5초 후 저장하며, 설정 적용 시에도 저장합니다.

키 파일의 구조는 다음과 같습니다. 아래 값은 실제 키가 아닌 자리표시자입니다.

```json
{
  "kie_api_key": "YOUR_KIE_API_KEY",
  "deepl_api_key": "YOUR_DEEPL_API_KEY"
}
```

- 파일에 해당 항목이 없으면 `KIE_API_KEY`, `DEEPL_API_KEY` 환경 변수를 읽습니다. 빈 문자열을 포함해 파일에 항목이 있으면 파일 값이 우선합니다.
- `.env` 파일을 자동으로 읽는 기능은 없습니다.
- 이전 형식의 `kie-api-key.json`, `deepl-api-key.json`이 있으면 통합 파일로 옮기고 저장을 확인한 뒤 이전 파일을 제거합니다.
- OCR 모델은 기본적으로 `.models/`에 캐시됩니다. 외부에서 지정한 `HF_HOME`이 있으면 Hugging Face 캐시 경로가 달라질 수 있습니다.
- 상태와 오류는 `manga-live.log`에 기록합니다.
- 가상환경, 모델, 로그, API 키 파일, 로컬 실행 메모 `시작방법.txt`는 `.gitignore`로 Git 추적에서 제외합니다.

## 문제 해결과 한계

| 증상 | 확인할 내용 |
| --- | --- |
| API 키를 입력하라는 메시지 | 선택한 서비스에 맞는 키를 입력하고 **설정 적용**을 누릅니다. |
| 첫 번역이 오래 걸림 | OCR 모델 다운로드·로딩이 진행 중인지 상태창을 확인합니다. |
| 작은 글씨나 말풍선을 놓침 | 영역을 좁히거나 원본/정밀 감지 또는 말풍선 하나 모드를 사용합니다. |
| GPU를 사용할 수 없음 | CPU 모드로 바꾸고 설정을 적용하거나 NVIDIA 드라이버와 PyTorch 환경을 확인합니다. |
| 아래 창 캡처 실패·응답 지연 | 대상 앱이 정상 동작하는지 확인하고, 번역기 창을 영역 밖으로 옮긴 뒤 다시 시도합니다. |
| API 연결 실패·한도 오류 | 인터넷 연결, 키, 서비스 사용 한도를 확인하고 **다시 번역**을 누릅니다. |
| 스크롤 후 번역 위치가 어긋남 | 화면 이동을 멈추고 **다시 번역**을 누릅니다. |

번역 방향은 일본어 → 한국어로 고정되어 있습니다. 효과음, 세로쓰기, 작은 글자, 복잡한 배경에서는 OCR 오류가 발생할 수 있습니다. 말풍선 단위로 번역하므로 장면 전체의 맥락을 충분히 반영하지 못할 수 있습니다.

창 캡처와 화면공유의 결과는 대상 앱과 캡처 방식에 따라 달라질 수 있습니다. 프로그램 UI에는 Discord에서 **Manga Live · 일본어 → 한국어** 창을 선택하라는 안내가 있으며, 모든 공유 환경에서의 표시를 보장하지는 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `main.py` | UI, 드래그 선택, 작업 큐, 자동 번역 감시, 번역 표시 |
| `core.py` | 글자 영역 병합, 화면 변화 감지, 스크롤 및 위치 추적 |
| `ocr_backends.py` | OCR 모드, CPU/GPU 선택, 감지와 인식 |
| `translation.py` | Kie·DeepL API 요청 및 응답 처리 |
| `window_capture.py` | 화면 캡처 및 번역기 창에 가려진 영역 복원 |
| `api_settings.py` | API 키 로딩, 저장, 이전 형식에서의 이동 |
| `hotkeys.py` | Windows 전역 단축키 등록, 설정 UI 및 저장 |
| `requirements.txt` | Python 의존성 목록 |
| `setup.bat` / `run.bat` | 설치 및 가상환경 실행 |
