# Manga OCR Translator

Windows 화면의 일본어를 인식하고, 한국어 번역을 원래 글자 위치에 겹쳐 보여주는 로컬 OCR 번역 프로그램입니다. 만화가 표시된 브라우저나 이미지 뷰어에서 번역할 영역을 지정해 사용할 수 있습니다.

> **AI 창작물 안내**  
> 이 프로젝트는 사용자의 요청을 바탕으로 AI가 코드를 작성한 창작물입니다. 이 README 역시 AI가 작성했습니다. 사용된 외부 라이브러리와 사전 학습 모델은 각 제작자의 별도 저작물입니다. OCR과 번역 결과에는 오류가 있을 수 있습니다.

## 주요 기능

- **일본어 → 한국어 번역**: 선택한 화면 영역에서 일본어를 인식하고 한국어로 번역합니다.
- **화면 위 번역 표시**: 말풍선별로 처리가 끝나는 즉시 번역을 표시합니다. 번역 표시창은 마우스 입력을 통과시킵니다.
- **화면 변화 감지**: 선택 영역의 내용이 바뀌면 다시 처리하고, 스크롤 시 기존 번역의 위치를 추적합니다.
- **OCR 방식 선택**: Manga OCR, EasyOCR, OpenCV 기반 감지를 선택할 수 있습니다.
- **CPU / GPU 선택**: CPU 또는 NVIDIA CUDA GPU로 모델을 실행할 수 있습니다.
- **말풍선 하나 모드**: 자동 영역 감지를 생략하고 선택 영역 전체를 하나의 글자 영역으로 인식합니다.
- **감지 크기 조절**: 빠른 감지, 균형 감지, 정밀 감지를 제공합니다.
- **화면공유 옵션**: 번역 표시를 화면 캡처에 포함할지 선택할 수 있습니다.

## 동작 방식

```text
화면 영역 선택 → 화면 캡처 → 글자 영역 감지 → 일본어 OCR
             → NLLB 한국어 번역 → 원래 위치에 번역 표시
```

OCR은 이미지 속 글자를 텍스트로 읽는 기능입니다. 번역에는 `facebook/nllb-200-distilled-600M` 모델을 사용합니다.

| OCR 모드 | 글자 영역 감지 | 글자 인식 |
| --- | --- | --- |
| Manga OCR — 기본값 | EasyOCR | Manga OCR |
| EasyOCR | EasyOCR | EasyOCR |
| OpenCV | OpenCV | Manga OCR |

OpenCV 영역 감지는 CPU에서 실행됩니다. 말풍선 하나 모드를 사용하면 영역 감지를 생략합니다.

## 실행 환경

- **Windows 전용** 프로그램입니다.
- Python **3.11 이상**이 필요합니다. 코드에서 `asyncio.Runner`를 사용합니다. 실제 설치 가능 버전은 의존성 패키지의 지원 범위에도 영향을 받습니다.
- `setup.bat`을 사용하려면 Windows Python 런처인 `py` 명령을 사용할 수 있어야 합니다.
- 패키지 설치와 모델 최초 다운로드에는 인터넷 연결이 필요합니다.
- GPU 모드에는 CUDA를 사용할 수 있는 NVIDIA GPU, 드라이버 및 PyTorch 환경이 필요합니다.
- Windows의 캡처 제외 기능에는 **Windows 10 2004 이상**이 필요합니다.

현재 `requirements.txt`는 CUDA 13.0용 PyTorch 패키지를 지정합니다. 앱의 기본 실행 모드는 CPU이지만, 설치 스크립트가 CPU 전용 패키지를 자동으로 선택하지는 않습니다. 패키지 버전이나 Python 환경이 맞지 않으면 설치가 실패할 수 있습니다.

## 설치 및 실행

1. 저장소를 다운로드하거나 복제한 뒤 폴더를 엽니다.
2. `setup.bat`을 실행합니다. `.venv` 가상환경을 만들고 필요한 패키지를 설치합니다.
3. 설치가 완료되면 `run.bat`을 실행합니다.
4. 첫 실행에는 OCR과 번역 모델을 다운로드하고 불러오므로 시간이 걸릴 수 있습니다. 상태창에 준비 완료가 표시될 때까지 기다립니다.

직접 명령을 실행하려면 프로젝트 폴더의 PowerShell에서 다음을 입력합니다.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 사용 방법

1. 번역할 만화를 브라우저나 이미지 뷰어에 표시합니다.
2. 프로그램에서 대상 모니터를 선택합니다.
3. 필요하면 CPU/GPU와 OCR 방식을 선택하고 **CPU/GPU·OCR 모드 적용**을 누릅니다. 모델을 다시 불러온 뒤 사용합니다.
4. **영역 선택**을 누르고 번역할 부분을 드래그합니다. `Esc`를 누르면 선택을 취소합니다.
5. 모델 로딩과 영역 선택이 완료되면 **시작**을 누릅니다.
6. 선택 영역의 일본어가 한국어로 표시됩니다. 스크롤하거나 화면 내용을 바꾸면 변화를 감지해 처리합니다.
7. 결과를 새로 읽으려면 **다시 번역**, 감시를 멈추려면 **일시정지**를 누릅니다. 프로그램 창을 닫으면 종료됩니다.

### 인식이 잘되지 않을 때

- 말풍선 하나만 좁게 선택한 뒤 **선택 영역 전체가 말풍선 하나**를 켜 보세요.
- 작은 글씨를 놓치면 **정밀 감지**로 변경해 보세요. 처리 시간은 늘어날 수 있습니다.
- 번역 위치가 어긋나거나 화면 변경을 놓치면 **다시 번역**을 누르세요.
- 제어창이 번역 영역 안에 있고 캡처 제외 기능을 사용할 수 없다면 제어창을 영역 밖으로 옮기세요.

### 화면공유

**화면공유에 번역 표시**는 기본적으로 켜져 있습니다. 번역 표시창을 캡처에 포함하도록 설정하며, Discord 등에서 전체 화면 공유를 사용하는 용도입니다. 실제 표시 여부는 화면공유 앱과 캡처 방식에 따라 달라질 수 있습니다.

번역 표시로 가려진 부분만 바뀌면 화면 변화를 놓칠 수 있습니다. 이 경우 **다시 번역**을 누르세요.

## 로컬 처리와 저장 파일

- 화면 이미지와 인식한 대사는 앱의 OCR·번역 처리 과정에서 외부 번역 서버로 전송하지 않고 로컬 모델로 처리합니다. 별도 번역 API 키는 사용하지 않습니다.
- 패키지와 모델 다운로드를 위한 네트워크 연결은 발생합니다. 필요한 모델이 캐시에 있으면 이를 재사용합니다.
- 모델은 기본적으로 `.models/`에 저장합니다. 외부에서 `HF_HOME`을 지정한 경우 일부 Hugging Face 캐시 위치는 달라질 수 있습니다.
- 실행 상태와 오류는 `manga-live.log`에 기록합니다.
- `.venv/`, `.models/`, Python 캐시, 로그, `.env` 파일 및 로컬 실행 메모인 `시작방법.txt`는 Git 추적 대상에서 제외합니다.

## 현재 한계

- 번역 방향은 **일본어 → 한국어**로 고정되어 있습니다.
- 글씨체, 세로쓰기, 효과음, 작은 글자, 복잡한 배경에 따라 인식이 부정확할 수 있습니다.
- 문장별로 번역하므로 앞뒤 대화의 맥락이나 인물의 말투를 충분히 반영하지 못할 수 있습니다.
- 화면을 감시하지만 번역 완료까지 걸리는 시간은 하드웨어, 선택 영역, 감지 모드에 따라 달라집니다.
- 스크롤 추적이 항상 성공하는 것은 아닙니다. 빠른 화면 이동이나 복잡한 화면 변화에서는 재번역이 필요할 수 있습니다.
- 원본 이미지 파일에 번역을 저장하거나 만화 파일을 일괄 변환하는 기능은 없습니다. 번역은 화면 위에 표시됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `main.py` | 프로그램 UI, 화면 캡처, 작업 처리 및 번역 오버레이 |
| `core.py` | 글자 영역 병합, 화면 변화 감지, 스크롤 및 위치 추적 |
| `ocr_backends.py` | OCR 방식 선택과 영역 감지·글자 인식 |
| `translation.py` | NLLB 모델 로딩과 일본어 → 한국어 번역 |
| `requirements.txt` | Python 의존성 목록 |
| `setup.bat` | 가상환경 생성 및 의존성 설치 |
| `run.bat` | 가상환경의 Python으로 프로그램 실행 |

## 문제 확인

설치가 실패하면 `setup.bat` 창의 오류 메시지를 확인하세요. 실행 중 문제가 발생하면 프로그램 상태창과 `manga-live.log`를 확인하세요. GPU를 사용할 수 없다는 메시지가 나오면 **CPU 모드**로 변경하고 **CPU/GPU·OCR 모드 적용**을 누르세요.
