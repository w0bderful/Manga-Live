# Manga Live

화면 속 일본어·영어를 읽고 **한국어 번역을 원문 위치에 표시하는 Windows용 만화 번역기**입니다. 브라우저나 이미지 뷰어에 열린 만화에서 원하는 부분을 드래그해 한 번 번역하거나, 선택 영역의 변화를 계속 감지해 번역할 수 있습니다.

외부 라이브러리와 사전 학습 모델은 각 제작자의 별도 저작물입니다.

## 주요 기능

- **드래그 번역**: 영역을 드래그한 뒤 놓으면 바로 한 번 번역합니다.
- **자동 번역**: 선택 영역의 화면 변화를 감지하고 스크롤에 맞춰 번역 위치를 추적합니다.
- **원문 위치에 표시**: 말풍선별로 번역이 끝나는 즉시 화면 위에 표시합니다. 마우스 입력은 아래 앱으로 통과합니다.
- **원문 방향에 맞춘 표시**: 영어 가로 문장은 말풍선이 길쭉해도 가로쓰기를 유지합니다. 일본어 세로쓰기는 한글을 위에서 아래로, 열은 오른쪽에서 왼쪽으로 배치합니다. 감지한 줄의 방향을 유지하며 번역 길이에 맞춰 줄바꿈과 글자 크기를 조절합니다.
- **통합 OCR**: Comic Text Detector로 영역을 감지하고(기존 OpenCV 방식으로 전환 가능), 일본어는 Manga OCR, 영어는 TrOCR·EasyOCR로 읽습니다. CPU·NVIDIA GPU 실행을 지원합니다.
- **번역 API 선택**: Luna(Kie), DeepL Free·Pro, 주소를 지정하는 OpenAI 호환 API를 지원합니다.
- **설정 저장**: API 키는 별도 파일에, 원문 언어·호환 서버 주소·모델·번역 서비스·단축키·글자 표시 설정은 settings.json 하나에 저장합니다.
- **화면 구성**: 기본·고급 모드, 별도 설정창, 프로그램 창 최상단 고정을 제공합니다. 창 배경은 시스템과 동일·라이트·다크·벚꽃 중 선택하고 저장합니다. 벚꽃 배경은 꽃잎이 천천히 움직이며 버튼·입력칸을 어두운 단색으로 구분합니다. 숨기거나 최소화하면 애니메이션은 멈춥니다.

## 설치와 실행

### 준비 사항

- Windows와 `python` 명령으로 실행할 수 있는 Python이 필요합니다. 코드에는 Python 3.11 이상의 기능을 사용하며, 설치할 버전은 의존성 패키지의 지원 범위에도 맞아야 합니다.
- 처음에는 패키지와 OCR 모델을 다운로드할 인터넷 연결이 필요합니다.
- 번역에는 사용할 서비스의 API 접근 권한이 필요합니다. 인증이 없는 로컬 OpenAI 호환 서버는 키를 비워 사용할 수 있습니다.

현재 `requirements.txt`는 CUDA 13.0용 `torch==2.14.0+cu130`, `torchvision==0.29.0+cu130`을 지정합니다. OCR 처리 장치는 마지막 선택을 복원하며, 저장값이 없으면 **GPU 모드**로 시작합니다. 호환 NVIDIA GPU를 사용할 수 없다면 설정에서 **CPU 모드**를 선택하세요. 변경은 자동으로 적용됩니다. 설치 스크립트가 CPU 전용 패키지로 자동 전환하지는 않습니다.

### BAT 파일 사용

저장소를 다운로드하거나 복제한 뒤 프로젝트 폴더에서 실행합니다.

| 파일 | 용도 |
| --- | --- |
| `setup.bat` | 가상환경 `.venv` 생성, 의존성 설치 후 프로그램 실행 |
| `run.bat` | 이미 설치된 가상환경으로 프로그램 실행 |

처음에는 `setup.bat`, 이후에는 `run.bat`을 사용하세요. Python이 없으면 `setup.bat`은 가상환경 생성 실패를 한국어로 안내하고 종료합니다. Python을 자동 설치하지 않습니다.

`run.bat`은 CMD 창을 최소화해 실행합니다. 실행 오류가 나면 작업 표시줄에서 CMD 창을 복원해 한국어 안내와 원래 오류 출력을 확인하세요. 가상환경이 없으면 먼저 `setup.bat`을 실행하라는 안내가 나옵니다.

### PowerShell에서 직접 실행

프로젝트 폴더에서 다음 명령을 실행합니다. 가상환경의 Python을 직접 사용하므로 별도의 활성화 명령은 필요하지 않습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

다음 실행부터는 마지막 명령만 사용하면 됩니다.

### EXE 만들기 (auto-py-to-exe)

의존성을 설치한 가상환경에서 다음 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build_exe.py
```

`auto-py-to-exe.json` 설정을 읽어 auto-py-to-exe의 빌드 기능으로 **`output/Manga Live/Manga Live.exe`**를 만듭니다. GPU 라이브러리가 크므로 폴더형으로 생성합니다. 실행할 PC에는 Python을 따로 설치할 필요가 없지만, GPU 사용에는 호환 NVIDIA 드라이버가 필요합니다.

- 배포·이동할 때는 `_internal`을 포함한 **`Manga Live` 폴더 전체**를 함께 옮기세요.
- 설정·API 키·로그·모델은 EXE와 같은 폴더 아래에 저장합니다. 쓰기 가능한 폴더에서 실행하세요.
- 개인 API 키와 설정은 빌드에 포함하지 않습니다. EXE에서 다시 설정하거나 본인 PC에서 필요한 설정 파일을 직접 복사하세요.
- 모델은 최초 실행 시 다운로드합니다. 이미 다운로드한 프로젝트의 `.models` 폴더를 EXE 옆에 복사하면 재사용할 수 있습니다.
- 재빌드할 출력 폴더에 설정·로그·모델이 있으면 사용자 데이터 보호를 위해 중단합니다. 해당 폴더를 별도로 보관한 뒤 다시 빌드하세요.

### 통합 EXE 만들기

배포용 **Manga Live.exe 하나**가 필요한 라이브러리를 설치하고 같은 프로세스에서 프로그램을 실행합니다. 별도의 설치기나 `Manga Live App.exe`를 실행하지 않습니다.

```powershell
.\.venv\Scripts\python.exe build_exe.py --runtime --output output/integrated-runtime
.\.venv\Scripts\python.exe build_downloader.py --source "output/integrated-runtime/Manga Live" --asset-base-url http://103.244.118.48/런타임태그
```

`output/downloader/Manga Live.exe`와 `Manga-Live-runtime-*.zip`이 생성됩니다. ZIP 파일은 Ubuntu 서버의 `/srv/manga-live/런타임태그/`에 먼저 게시하고, GitHub의 사용자용 릴리스에는 EXE 하나만 올립니다. 사용자는 EXE 하나를 받고 실행하면 됩니다. 다운로드한 파일은 EXE에 포함된 크기와 SHA-256으로 검증합니다.

런타임 내용이 같고 서버 주소만 옮기는 경우 `build_downloader.py --relocate-runtime --asset-base-url 새주소`로 기존 매니페스트의 다운로드 주소만 변경하고 EXE를 다시 만듭니다. ZIP은 다시 압축하지 않으며 기존 파일을 새 서버로 복사합니다. 이전 GitHub 런타임 릴리스는 정리되었으므로 처음 설치하거나 런타임 복구가 필요하면 최신 릴리스의 EXE를 다시 받으세요.

- 첫 실행 때 진행률을 표시하며 필요한 파일을 다운로드·검증·압축 해제합니다. Python 설치는 필요하지 않습니다.
- 취소하거나 연결이 끊기면 다음 실행에서 다운로드를 재개합니다. 서버가 재개를 지원하지 않으면 해당 파일을 처음부터 다시 받습니다.
- 최초 설치 때 SHA-256과 파일 구성을 검사합니다. 정상 재실행에서는 전체 파일 검사를 건너뛰고 설치된 라이브러리를 사용합니다. 실행 진입 파일이 없거나 이전 시작 과정이 실패한 경우에만 다시 확인하고 필요한 파일을 복구합니다.
- 설치 완료 후 다운로드한 ZIP과 임시 압축 해제 폴더를 자동 삭제합니다. 완료되지 않은 다운로드는 이어받기를 위해 유지하며, 설치 완료 시 정리합니다.
- 의존성은 실행기 옆의 `.manga-live-runtime/`에, 사용자 설정·키·모델·로그는 실행기 옆에 저장합니다. 업데이트한 프로그램 창이 정상적으로 열리면 이전 버전의 런타임을 백그라운드에서 정리합니다. 현재 사용하는 런타임은 유지하며, 잠금·권한 문제로 정리하지 못한 폴더는 다음 실행에서 다시 정리합니다. `.manga-live-runtime/` 폴더 전체를 삭제하면 필요한 라이브러리를 다시 받아야 합니다. 쓰기 권한과 수 GB의 여유 공간이 필요합니다.
- OCR 모델은 앱의 첫 실행 때 별도로 다운로드합니다. GPU 실행에는 호환 NVIDIA GPU와 드라이버가 필요합니다.
- **1일(24시간)마다** 새 프로그램 릴리스(사전 릴리스 포함)를 확인하며, 창 아래의 **버전 확인** 버튼으로 언제든 확인할 수 있습니다. 런타임 릴리스는 업데이트 대상으로 보지 않습니다. 마지막 확인 시각은 `settings.json`에 저장합니다. 확인은 프로그램 실행 중에 이루어집니다.
- 새 버전이 있으면 다운로드 여부를 묻습니다. 동의하면 EXE를 받아 SHA-256을 검증하고, 완료 메시지 없이 프로그램을 자동으로 종료·교체·재시작합니다. 설정·키·모델은 유지합니다. 교체가 끝난 업데이트 다운로드 파일도 자동 삭제합니다. 재시작 준비에 실패하면 현재 프로그램을 유지하고 오류를 안내합니다.
- 업데이트 다운로드 퍼센트는 하단의 OCR·번역 진행바에 통합해 표시합니다. 다운로드 중에는 업데이트 진행률을 우선 표시하며, 실패하면 현재 OCR·번역 진행 상태로 돌아갑니다.
- 진행바는 진행률이 증가할 때 부드럽게 채워지며, 표시되는 수치와 처리 개수는 실제 진행 상태를 따릅니다.
- 업데이트 파일 다운로드나 검증이 실패하면 기존 EXE를 유지합니다. 소스 실행에서는 새 버전의 릴리스 페이지를 열 수 있습니다.
- 배포 빌드는 런타임 파일의 크기와 SHA-256을 이전 설치 정보와 비교합니다. 내용이 같으면 기존 다운로드 주소를 재사용하며 런타임 ZIP을 다시 만들거나 업로드하지 않습니다.

## 화면과 초기 설정

모니터, 기본·고급 모드, OCR 처리 장치, 감지 해상도, 말풍선 하나 모드, 최상단 고정은 마지막 선택을 저장하고 재실행 시 복원합니다. 저장값이 없으면 **기본 모드**, **GPU**, **원본 감지 해상도**, **말풍선 하나 모드 꺼짐**, **최상단 고정 켜짐**으로 시작합니다. 번역 서비스는 마지막 선택을 복원하고, 저장된 선택이 없으면 Luna를 사용합니다.

상단 메뉴바에는 **기본 모드**, **고급 모드**, **창 배경**이 있고, 오른쪽에 **최상단 고정** 체크박스가 있습니다.

| 화면 | 표시 내용 |
| --- | --- |
| 기본 모드 | 큰 실행 버튼 4개, 최상단 고정, 상태, DeepL 선택 시 잔여 한도 |
| 고급 모드 | 기본 화면에 모니터·API·OCR·해상도·단축키 등 모든 설정을 추가 표시 |
| 별도 설정창 | 프로그램 창에서 `Ctrl+,`를 누르면 열림 |

고급 모드에서 별도 설정창을 열면 설정 영역이 그 창으로 이동하고, 닫으면 메인 창으로 돌아옵니다. 기본·고급 모드 전환은 진행 중인 번역과 설정값을 유지합니다. **최상단 고정** 체크를 해제하면 프로그램 창을 일반 창처럼 사용할 수 있습니다.

처음 번역하기 전에 다음을 설정하세요.

1. **고급 모드** 또는 `Ctrl+,`로 설정을 엽니다.
2. 만화가 있는 **모니터**, **원문 언어**, **OCR 처리 장치**, **영역 감지**를 선택합니다.
3. **번역 API**를 선택하고 해당 키를 입력합니다. OpenAI 호환 API는 주소를 입력한 뒤 모델 목록을 불러와 선택합니다.
4. 설정이 자동으로 적용된 뒤 상태를 확인합니다.

API 키 입력칸은 입력한 문자를 그대로 표시합니다. API 키·주소·모델과 원문 언어·OCR 장치·영역 감지 방식을 바꾸면 마지막 변경 후 약 0.5초 뒤 자동으로 적용됩니다. 적용 중에는 현재 작업이 끝나기를 기다립니다. 연속 번역은 일시정지되므로 준비 완료 후 **번역 시작**으로 재개하세요.

시작 시 선택한 처리 장치에서 EasyOCR 일본어·영어, Manga OCR, 영어 TrOCR 모델을 백그라운드로 미리 불러옵니다. 캐시가 없으면 다운로드하므로 처음 준비에는 시간이 걸릴 수 있습니다. 같은 장치에서는 언어·API를 바꿔도 로딩한 모델을 재사용하며, CPU/GPU를 바꾸면 새 장치에서 다시 준비합니다. TrOCR 모델만 실패하면 영어는 EasyOCR로 계속합니다. Comic Text Detector를 선택하면 감지 모델도 미리 준비합니다. 하단 진행바는 OCR 준비 단계(Comic Text Detector 5단계, 기존 방식 4단계)와 현재 화면의 번역 처리 영역 수를 표시합니다. 모델 다운로드 중에는 하단 진행바에 모델 이름과 받은 용량·전체 용량·진행률을 표시합니다. 전체 전송량을 알 수 없는 Xet 압축 다운로드는 받은 용량만 표시합니다. 다운로드가 끝나면 모델 로딩 단계 표시로 돌아갑니다. 영역 감지 중에는 진행 중 표시를 사용합니다. 준비 완료 표시는 실제 API 인증이나 잔여 한도를 보장하지 않습니다.

## 번역 방법

**영역 선택**으로 지정한 범위 바깥에는 청록색 테두리가 표시됩니다. 일반 영역 선택의 테두리는 번역 완료·일시정지 후에도 유지됩니다. **드래그 번역**은 선택 완료 후 같은 테두리를 표시하고 **3초 후 자동으로 숨깁니다**. 새 영역 선택을 시작하거나 프로그램을 종료하면 테두리가 사라집니다. 테두리는 마우스 조작을 막지 않습니다.

### 드래그한 영역을 한 번 번역

1. **드래그 번역**을 누릅니다.
2. 번역할 영역을 드래그한 뒤 놓습니다.
3. 선택 영역을 한 번 캡처해 자동 번역하고 결과를 화면에 남깁니다.

별도의 시작 조작은 필요하지 않습니다. 이 방식은 화면 변화와 스크롤을 추적하지 않습니다. 같은 위치의 현재 화면을 새로 읽으려면 **다시 번역**, 다른 영역을 지정하려면 **드래그 번역**을 누르세요. 처리 중에는 **취소**, 영역 선택 중에는 `Esc` 또는 마우스 오른쪽 클릭으로 중단할 수 있습니다.

번역 설정 적용을 기다리는 동안에는 캡처한 이미지를 유지하고 준비 후 자동 처리합니다. 대기 중 취소하면 자동 재개하지 않습니다. 완료 후 **번역 시작**을 누르면 같은 영역을 계속 감시하는 방식으로 전환하고 청록색 테두리를 표시합니다.

### 선택 영역을 계속 번역

1. **영역 선택**을 누르고 감시할 부분을 드래그합니다.
2. **번역 시작**을 누릅니다.
3. 화면 변화가 잠시 멈추면 OCR과 번역을 수행합니다. 스크롤 시 기존 번역 위치를 추적합니다.

**일시정지**를 누르면 감시를 멈추고 표시된 번역을 지웁니다. **다시 번역**은 현재 결과를 초기화하며, 감시 중이면 다음 캡처부터 재처리합니다. 일시정지 중에는 **번역 시작**을 눌러야 처리됩니다.

같은 이미지나 문장의 결과는 메모리 캐시에서 재사용할 수 있으므로 다시 번역을 눌러도 매번 새로운 API 요청을 보내는 것은 아닙니다.

### 말풍선 하나만 인식

말풍선 하나를 좁게 선택하고 **선택 영역 전체가 말풍선 하나 (자동 감지 생략)**를 켜세요. 글자 영역을 자동으로 찾는 과정을 생략하고 선택 영역 전체를 OCR에 전달합니다.

## 단축키

다음 네 가지는 다른 앱에 포커스가 있어도 작동하는 전역 단축키입니다.

| 기능 | 기본값 |
| --- | --- |
| 영역 선택 | `Ctrl+Alt+1` |
| 드래그 번역 | `Ctrl+Alt+2` |
| 번역 시작 / 일시정지 / 처리 중 취소 | `Ctrl+Alt+3` |

설정의 **단축키 설정**에서 입력칸을 클릭해 원하는 키 조합을 누르고 **저장**하세요. **해제**로 비우거나 **기본값 불러오기**로 되돌린 뒤 저장할 수 있습니다.

- 일반 키는 `Ctrl`, `Alt`, `Shift`, `Win` 중 하나 이상과 조합합니다. F키는 단독 지정도 가능합니다.

- 단축키 편집 중에는 전역 단축키를 잠시 해제하고, 취소하면 기존 설정을 복원합니다.
- 영역 선택 및 번역 설정 적용 중에는 전역 단축키 실행을 막습니다. 영역 선택 취소는 `Esc` 또는 마우스 오른쪽 클릭을 사용하세요.

`Ctrl+,`는 프로그램 창에서 별도 설정창을 여는 고정 단축키입니다.

## 프로그램 사용량

메인 창 하단에 현재 Manga Live 프로세스의 **CPU·GPU 사용률과 VRAM 사용량**을 표시합니다. CPU는 전체 논리 코어 용량 기준이며 GPU는 이 프로세스가 사용하는 엔진 중 가장 바쁜 엔진 기준입니다. VRAM은 전용 GPU 메모리의 합계이며 다른 프로그램의 사용량은 포함하지 않습니다. GPU 집계 기준은 [Windows 작업 관리자 설명](https://devblogs.microsoft.com/directx/gpus-in-the-task-manager/)을 따릅니다.

OCR로 화면을 읽거나 번역 응답을 기다리는 동안에는 **1초**, 그 외 준비·화면 변화 대기·일시정지 상태에서는 **3초**마다 갱신합니다. Windows 성능 카운터에 표본이 없거나 드라이버가 정보를 제공하지 않으면 해당 값은 `—`로 표시합니다. 사용량 조회 실패는 번역을 중단하지 않습니다.

## 창 배경

상단 메뉴바의 **창 배경**에서 **시스템과 동일 · 라이트 · 다크 · 벚꽃**을 선택할 수 있습니다. 기본값은 벚꽃이며 변경 즉시 메인 창과 설정창에 반영하고 `settings.json`에 저장합니다. 기본·고급 모드 모두 같은 메뉴에서 선택합니다. 라이트·다크는 Windows 기본 컨트롤 스타일을 사용하고, 시스템과 동일은 Windows의 현재 밝기 설정을 따릅니다. 이 설정은 번역문 표시 스타일과 별개입니다.

일반 설정은 모니터·OCR 처리 장치, 번역 API·원문 언어를 한 줄에 두 개씩 표시하고, 영역 감지·감지 해상도도 한 줄에 두 개씩 표시합니다.

## 번역 글자 표시

번역문은 검은 윤곽선이 있는 굵은 흰색 글자로 표시합니다. 감지 영역이 일부 겹치면 표시 공간을 나누고 각 공간에 맞게 글자를 줄여 번역문끼리 겹치지 않도록 합니다. OCR에 전달하는 원본 영역은 유지합니다. **고급 모드**에서 다음 값을 조절할 수 있습니다.

- **글꼴**: PC에 설치된 글꼴 선택. 기본값은 맑은 고딕입니다.
- **글자 크기**: 8~72px, 기본 23px. 영역이 작거나 번역문이 길면 영역에 맞게 자동으로 줄어듭니다.
- **배경 불투명도**: 번역 영역의 흰색 배경을 0~100%로 조절합니다. 기본 30%, 0%는 배경 없음, 100%는 완전 불투명입니다. 글자 자체의 진하기는 유지합니다.

변경은 화면에 즉시 반영되며 `settings.json`에 저장해 재실행 시 복원합니다. 기본 모드에서도 선택한 값이 적용됩니다.

## 원문 언어

설정의 **원문 언어**에서 다음 항목을 선택합니다. 변경은 자동 적용되며 `settings.json`에 저장해 다음 실행에도 복원합니다. 새 설정 파일이 없으면 기존 동작과 같은 **일본어**를 사용합니다.

| 선택 | 동작 |
| --- | --- |
| 자동 언어 감지 | EasyOCR로 이미지의 일본어·영어를 먼저 판별한 뒤 해당 언어의 OCR 경로를 선택합니다. |
| 일본어 | 일본어 OCR과 일본어 → 한국어 번역을 사용합니다. |
| 영어 | 영어 OCR과 영어 → 한국어 번역을 사용합니다. |

자동 감지는 선택한 감지 방식으로 찾은 영역마다 문자 종류와 인식 신뢰도를 비교합니다. 세로쓰기로 판별이 어려우면 글자를 가로로 정렬해 EasyOCR로 다시 판별합니다. 일본어는 Manga OCR로 읽고, 영어는 TrOCR와 EasyOCR로 읽습니다. 한 화면에 두 언어가 섞여 있어도 영역별로 처리합니다. 끝내 언어를 판별하지 못하면 **Manga OCR로 인식을 시도**하고 그 결과를 일본어로 번역합니다. 글자가 없는 단색 영역은 건너뜁니다. 현재 지원 범위는 일본어·영어이며, 영어가 계속 잘못 인식되면 원문 언어를 영어로 직접 선택하세요.

작은 세로 글자의 언어 판별을 재시도할 때는 글자를 확대하고, 필요하면 가장자리의 말풍선·칸 테두리를 제외한 부분으로 판별합니다. 실제 문장 인식에는 전체 글자 영역을 사용합니다.

기존 OpenCV 방식은 글줄을 묶을 때 말풍선의 흰 내부와 어두운 테두리, 글줄 시작 위치를 함께 확인합니다. 제목이나 기울어진 주석 때문에 다른 말풍선까지 한 영역으로 커지는 것을 줄이고, 감지된 작은 닫힌 말풍선에서는 바깥으로 벗어난 여백과 중복 영역을 정리합니다. 감지 영역을 가로지르는 가는 검은 세로 칸 경계도 분리합니다. 모든 말풍선 모양을 정확하게 구분하지는 못하며, 열린 테두리·복잡한 배경·매우 작은 글자·효과음에는 누락이나 오인식이 남을 수 있습니다.

영어는 **영역 감지 → EasyOCR로 줄 분리 → 글씨 형태 추정 → 인식기 선택** 순서로 처리합니다. 각 줄의 글자 높이와 기준선 규칙성을 OpenCV로 확인합니다. 일반 인쇄체로 추정되면 EasyOCR로 먼저 읽고, 인식 신뢰도가 낮으면 [TrOCR 손글씨 모델](https://huggingface.co/microsoft/trocr-small-handwritten)로 보완합니다. TrOCR 결과도 불확실하면 먼저 얻은 EasyOCR 결과를 유지합니다. 손글씨·장식체로 추정되거나 형태를 판별하기 어려우면 TrOCR로 먼저 읽고, 실패하거나 단어·문자 형태가 불확실하면 EasyOCR로 읽습니다.

글씨 형태 확인은 이미지 모양에 따른 보수적인 추정이며, 폰트 이름을 찾거나 별도 분류 모델을 사용하는 기능은 아닙니다. 규칙적인 손글씨나 특수 인쇄체는 잘못 분류될 수 있으며, 고유명사·작은 글자·숫자도 여전히 오인식할 수 있습니다. 별도 설정 없이 영어 영역마다 자동 적용됩니다.

TrOCR도 프로그램 시작 시 미리 준비하며, 모델이 없으면 `.models/`에 다운로드하고 이후에는 로컬 캐시를 사용합니다. 영어는 두 인식 모델을 사용하므로 CPU에서는 대기 시간이 더 길어질 수 있습니다. 화면 이미지는 외부로 전송하지 않습니다. 기존 설치에서 업데이트했다면 `setup.bat`으로 추가 의존성을 설치하세요.

기존 OpenCV 방식에서 OpenCV 감지 결과가 없거나 실행이 실패하면 EasyOCR 감지기의 영역을 사용합니다. TrOCR 모델을 불러오거나 실행하지 못하면 EasyOCR로 글자를 읽습니다. 같은 실행에서는 실패한 TrOCR 모델을 줄마다 재시도하지 않습니다. 다시 시도하려면 프로그램을 재실행하세요.

자동 감지에서도 판별된 일본어·영어를 번역 API에 원문 언어로 전달합니다. 번역 결과 언어는 항상 한국어입니다.

## OCR 설정

글자 인식 경로는 하나로 통합되어 있으며, **영역 감지**만 다음 두 방식 중 선택합니다. 선택은 자동 적용되고 `settings.json`에 저장·복원됩니다.

- **Comic Text Detector** — 기본값. 만화용 학습 모델의 텍스트 블록·줄 확률 지도로 영역을 찾습니다.
- **OpenCV (기존 방식)** — 기존 OpenCV 후보 감지 + EasyOCR/CRAFT 검증 + 말풍선·칸 경계 보정 과정을 그대로 사용합니다. 언제든 다시 선택할 수 있습니다.

Comic Text Detector는 공식 ONNX 모델(약 95MB)을 처음에 다운로드하고 SHA-256을 검증합니다. 저장 위치는 `.models/comic-text-detector/`입니다. **OCR 처리 장치** 선택을 감지 모델에도 적용합니다. GPU 모드는 ONNX Runtime CUDA, CPU 모드는 OpenCV DNN으로 같은 ONNX 모델을 실행합니다. 기존 설치에서 GPU 기능을 사용하려면 `setup.bat`으로 `onnxruntime-gpu==1.30.0`을 설치하세요. GPU 초기화 실패 시 CPU로 자동 전환하지 않고 오류를 표시합니다. CPU 모드를 직접 선택해 계속 사용할 수 있습니다. 다운로드·모델 로딩·감지 실패 시 오류를 표시하고, 설정에서 기존 OpenCV 방식으로 돌아갈 수 있습니다. 실패를 숨기고 자동으로 선택값을 변경하지 않습니다.

고정 1024 입력 모델에 작은 이미지를 원래 크기로 넣고, 큰 이미지는 전체 축소본과 겹치는 조각을 함께 감지해 좌표를 원본으로 복원합니다. 감지 해상도를 낮추면 조각 수가 줄지만 작은 글자를 놓칠 수 있습니다. 말풍선 외곽이나 한국어 배치를 직접 생성하는 모델은 아닙니다. 모델 출처·라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.

CTD의 큰 블록을 그대로 번역하지 않고 글줄 간격·쓰기 방향·말풍선 경계를 확인해 문장 영역을 나눕니다. 같은 문장의 글줄과 조각별 중복 감지는 합쳐서, 인접 말풍선의 대사가 섞이거나 같은 대사가 겹쳐 표시되는 경우를 줄입니다.

| 단계 | 처리 |
| --- | --- |
| 영역 감지 | Comic Text Detector 또는 기존 OpenCV·EasyOCR 방식 |
| 이미지 보정 | OpenCV로 저대비 이미지 보정 |
| 자동 언어 판별 | EasyOCR로 일본어·영어 판별 |
| 일본어 인식 | Manga OCR |
| 영어 인식 | 글씨 형태 추정 후 인쇄체는 EasyOCR 우선, 손글씨·불확실한 형태는 TrOCR 우선. 실패·불확실 시 다른 인식기로 보완 |

원문 언어와 CPU·GPU 처리 장치는 계속 선택할 수 있으며 선택값을 저장·복원합니다. **선택 영역 전체가 말풍선 하나**를 켜면 영역 감지를 생략하지만 이미지 보정과 영어 줄 분리·대체 인식은 유지합니다.

**OpenCV 이미지 보정을 공통 적용**합니다. 감지한 글자 영역을 읽기 전과 자동 언어 판별 전에 저대비 이미지를 흑백으로 변환하고 대비를 높인 뒤 약하게 선명화합니다. 이미 선명하거나 거의 단색인 이미지는 원본을 유지합니다. 일본어 Manga OCR, 영어 TrOCR와 대체 EasyOCR에 적용하며 말풍선 하나 모드에서도 동작합니다. 강한 이진화나 크기 변경은 하지 않고, 원본 캡처와 번역 표시 좌표를 보존합니다. 보정 오류 시 원본으로 계속 인식합니다. 별도 선택 없이 항상 적용되지만 모든 이미지에서 인식률 향상을 보장하지는 않습니다.

OCR은 로컬에서 수행합니다. CPU·GPU 선택은 Comic Text Detector와 기존 OCR 모델에 적용됩니다. OpenCV 후보 감지·이미지 보정과 CTD 좌표 후처리는 CPU에서 실행됩니다. 기존 방식의 EasyOCR 감지기는 선택한 OCR 장치를 사용합니다.

감지 해상도는 **원본**, **빠른 감지(960)**, **균형 감지(1280)**, **정밀 감지(1920)** 중 선택합니다. 큰 영역과 높은 해상도는 처리 시간과 메모리가 더 필요할 수 있습니다. 작은 글자를 놓치면 영역을 좁히거나 원본 해상도·말풍선 하나 옵션을 사용해 보세요.

## 번역 API

번역 요청이 실패하거나 빈 결과가 오면 **1초 간격으로 최대 5회 재시도**합니다. 최초 요청을 포함해 최대 6회이며 Luna·DeepL·OpenAI 호환 API에 공통 적용됩니다. 성공하면 즉시 재시도를 멈추고, 모두 실패하면 오류를 표시합니다. 대기 중 취소·종료하면 추가 요청을 보내지 않습니다. 모델 목록과 DeepL 잔여 한도 조회에는 적용하지 않습니다.

### Luna (Kie API)

Kie API 키를 입력하면 자동으로 적용됩니다. 현재 구현은 `api.kie.ai`의 Responses 요청과 `gpt-5-6-luna` 모델 식별자를 사용합니다.

### DeepL API

**DeepL API (Free / Pro 자동 선택)** 항목에서 무료·유료 API 키를 모두 사용할 수 있습니다. 코드가 키의 `:fx` 접미사를 확인해 Free 서버를 선택하며, 그 외에는 Pro 서버를 사용합니다. 실제 인증과 접근 가능 여부는 API 응답으로 확인됩니다.

키 입력 후 **남은 번역 가능 문자**를 자동 조회합니다. 기본 모드에서는 메인 창에, 고급 모드에서는 DeepL API 키 입력칸 바로 아래에 표시합니다. 계정 한도와 키별 한도가 함께 있으면 더 적게 남은 값을 표시합니다. 제한이 없는 경우 **남은 한도: 제한 없음**으로 표시하며, 이는 무료 사용을 뜻하지 않습니다. 조회에 실패하면 오류를 표시합니다. 새 키를 입력하면 번역 설정에도 자동으로 적용됩니다.

### OpenAI 호환 API

1. **OpenAI 호환 API (주소 직접 입력)**를 선택합니다.
2. 서버의 **API 주소**와 **API 키**를 입력합니다. 인증이 없는 로컬 서버는 키를 비워도 됩니다.
3. **모델 선택**을 누르면 서버에서 목록을 불러옵니다. 조회가 끝나면 펼쳐지는 목록에서 사용할 모델을 선택합니다.
4. 선택한 모델이 자동으로 적용되면 번역을 시작합니다.

주소 예시는 `http://localhost:1234/v1`입니다. `/v1/chat/completions`까지 포함한 전체 주소도 입력할 수 있습니다. HTTP·HTTPS와 사용자 지정 포트를 지원하며, 경로 없는 서버 주소에는 `/v1/chat/completions`를 사용합니다.

모델 선택을 누를 때마다 목록을 새로 조회합니다. 조회 중에는 중복 요청을 보내지 않으며, 실패하면 모델 선택을 다시 눌러 재시도할 수 있습니다. 조회를 기다리다가 다른 항목을 누르거나 Esc로 취소하면 목록을 자동으로 펼치지 않습니다.

모델 목록은 해당 기본 경로의 `GET /models`에서 가져오며 이름 직접 입력은 지원하지 않습니다. 주소나 키를 바꾸면 목록과 선택을 지우므로 다시 불러와야 합니다. 같은 서버에서 목록을 갱신할 때 기존 모델이 남아 있으면 선택을 유지합니다.

번역에는 `model`, `messages`, `stream: false`를 사용하는 **Chat Completions** 요청을 보냅니다. 서버는 모델 목록 조회와 Chat Completions를 지원해야 합니다. 목록에 나타나더라도 번역 요청을 지원하지 않는 모델이 있을 수 있으며, Responses API만 지원하는 서버는 이 모드에서 사용할 수 없습니다.

## 처리 과정과 저장 정보

### 번역 작동 순서

```text
영역 선택 → 화면 캡처 → 글자 영역 감지 → 이미지 보정·원문 언어 판별
→ 언어와 글씨 형태에 맞는 OCR → 번역 API → 원문 위치에 한국어 표시
```

1. **모델 준비**: 프로그램을 켜면 선택한 CPU·GPU에서 OCR 모델과 선택한 감지 모델을 미리 불러옵니다. 키가 필요한 번역 서비스에서 API 키를 비워도 모델 준비는 끝내고 키 입력을 기다립니다.
2. **화면 캡처**: 드래그 번역은 선택을 마치면 한 번 캡처합니다. 연속 번역은 선택 영역의 화면 변화가 잠시 멈춘 뒤 처리합니다.
3. **글자 영역 감지**: 기본값인 Comic Text Detector로 글줄과 텍스트 블록을 찾고, 중복·줄 간격·쓰기 방향·말풍선 경계를 확인해 처리 영역을 정리합니다. OpenCV (기존 방식)를 선택하면 OpenCV 후보 감지 → EasyOCR/CRAFT 검증 → 말풍선·칸 경계 보정을 사용합니다. **말풍선 하나** 옵션은 이 자동 감지 단계를 생략합니다.
4. **이미지 보정과 언어 판별**: OpenCV로 저대비 이미지를 보정합니다. 원문 언어가 **자동**이면 EasyOCR로 각 영역의 일본어·영어를 판별하고, 언어를 직접 선택했다면 판별을 생략합니다. 자동 판별에 실패하면 Manga OCR로 읽고 일본어로 번역을 시도합니다. 글자가 없는 거의 단색인 영역은 건너뜁니다.
5. **글자 인식(OCR)**: 일본어는 Manga OCR로 읽습니다. 영어는 작은 영역을 최대 3배 확대하고, 어두운 배경의 밝은 글자는 인식용 이미지의 명암을 반전합니다. 원본 화면과 표시 좌표는 유지합니다. EasyOCR로 영역 안의 글줄을 나누고, 각 줄의 글자 높이와 기준선 규칙성으로 글씨 형태를 추정해 아래 순서를 선택합니다. 폰트 이름을 알아내는 기능은 아니며 추정이 틀릴 수 있습니다.

   | 영어 글씨 형태 | 인식 순서 |
   | --- | --- |
   | 인쇄체로 추정 | EasyOCR → 결과가 없거나 신뢰도가 낮으면 TrOCR로 다시 인식. TrOCR 결과도 부적합하면 처음 EasyOCR 결과 유지 |
   | 손글씨·장식체로 추정 또는 판별 불확실 | TrOCR → 결과가 부적합하거나 실패하면 EasyOCR |

6. **한국어 번역**: 인식한 문장을 선택한 Luna(Kie)·DeepL·OpenAI 호환 API에 보냅니다. 요청 실패나 빈 응답은 1초 간격으로 추가 5회까지 재시도합니다(최초 포함 최대 6회). 취소·종료하면 추가 요청을 중단합니다.
7. **결과 표시**: 영역별 번역이 끝나는 즉시 원문 위치에 표시하고 진행바를 갱신합니다. 영어는 가로쓰기, 일본어는 감지한 원문 방향을 따르며 번역문 길이에 맞춰 글자 크기와 줄바꿈을 조절합니다. 연속 번역에서는 다음 화면 변화를 기다리면서 스크롤에 맞춰 위치를 추적합니다.

같은 이미지의 OCR 결과와 같은 문장의 성공한 번역은 메모리 캐시에서 재사용할 수 있습니다. 따라서 매번 모든 인식·API 요청을 다시 실행하지는 않습니다. OpenCV는 영역 감지·이미지 보정을 담당하며, 글자를 문장으로 읽는 인식기는 Manga OCR·TrOCR·EasyOCR입니다.

### 캡처와 외부 전송

번역 요청에는 **인식한 텍스트를 전송하며 화면 이미지는 포함하지 않습니다**. 외부 번역 서비스 이용에는 요금이 발생할 수 있습니다. OCR 모델 다운로드에도 네트워크를 사용합니다.

프로그램은 자신이 띄운 창을 캡처에서 제외하고 아래 창의 내용을 복원해 읽습니다. 캡처는 별도 보조 프로세스에서 처리하며, 응답이 5초 동안 없으면 해당 작업을 종료합니다. 오류 후 **다시 번역**하거나 영역을 새로 선택해 재시도할 수 있습니다.

### 로그와 보관 기간

`logs/translation-YYYY-MM-DD.log` 파일 하나에 입력과 출력을 함께 기록합니다. UTF-8 JSON Lines 형식으로 한 줄이 하나의 기록이며, `event`가 `input`이면 OCR 원문 입력, `output`이면 한국어 번역 결과 또는 실패 상태·오류 종류입니다.

입력과 출력은 같은 `id`로 연결됩니다. 시각, 번역 서비스, 캐시 재사용 여부도 기록하며 API 키·인증 헤더·화면 이미지는 기록하지 않습니다. 캐시에서 가져온 번역도 기록합니다. 출력 기록은 번역 결과를 받은 시점 기준이므로, 이후 취소로 화면에 표시되지 않은 결과도 포함될 수 있습니다.

**오늘을 포함한 최근 3일분**을 보관합니다. 프로그램 시작 시, 실행 중 1시간마다, 날짜가 바뀐 뒤 처음 기록할 때 오래된 실행·입출력 로그를 자동 삭제합니다. 종료 중에는 삭제 작업을 실행하지 않으며 다음 실행 때 정리합니다. 날짜 형식이 맞는 `translation-*.log`, `manga-live-*.log`와 이전 형식의 `input-*.jsonl`, `output-*.jsonl`에 적용합니다. 이전 실행 로그 `logs/manga-live.log`도 마지막 수정일 기준으로 3일 보관 후 삭제합니다. 다른 파일은 정리 대상에 포함하지 않습니다.

로그 쓰기에 실패해도 번역은 계속됩니다. 시작 시 로그 준비 실패는 창에 표시하고 실행 중 기록 실패는 실행 로그에 남깁니다. 입출력 로그에는 원문과 번역 내용이 저장되므로 공유할 때 내용을 확인하세요.

### 로컬 저장 파일

| 경로 | 내용 |
| --- | --- |
| `api-keys.json` | 번역 서비스별 API 키 |
| `settings.json` | 모니터, 기본·고급 모드, 모드별 창 크기, 최상단 고정, OCR 처리 장치, 영역 감지 방식, 감지 해상도, 말풍선 하나 모드, 원문 언어, 번역 서비스, OpenAI 호환 주소·모델, 단축키, 글꼴·크기·배경 불투명도, 창 배경 |
| `api-key-backups/` | 손상된 API 설정을 다시 저장할 때 보관하는 원본 |
| `.models/` | OCR 모델 캐시. 외부 `HF_HOME` 설정에 따라 일부 저장 위치가 달라질 수 있음 |
| `.venv/` | 가상환경과 설치 패키지 |
| `logs/manga-live-YYYY-MM-DD.log` | 날짜별 실행 상태·처리 시간·오류 로그, 최근 3일분 보관 |
| `logs/translation-YYYY-MM-DD.log` | 입력·출력을 합친 날짜별 번역 로그, 최근 3일분 보관 |

선택값은 `settings.json` 하나에 저장하며, 이전의 `hotkeys.json`·`overlay-settings.json`을 자동으로 옮기는 코드는 포함하지 않습니다.

위 로컬 저장 파일과 폴더는 Git 추적에서 제외합니다. API 키와 백업은 **평문으로 저장되므로 공유하지 마세요**. API 입력 변경은 약 0.5초 뒤 자동 저장·적용됩니다.

키 파일에 해당 항목이 없으면 `KIE_API_KEY`, `DEEPL_API_KEY`, `OPENAI_API_KEY` 환경 변수를 읽습니다. `.env` 파일을 자동으로 읽지는 않습니다. 화면에서 저장하면 환경 변수로 읽은 키도 파일에 기록될 수 있습니다. 이전 형식의 `kie-api-key.json`, `deepl-api-key.json`은 `api-keys.json`으로 이전하는 호환 처리가 있습니다.

설정 선택값은 변경 시 자동 저장됩니다. 저장된 모니터가 연결되어 있지 않으면 사용 가능한 첫 모니터를 선택합니다. 번역할 화면의 영역은 실행 후 다시 지정하며 번역을 자동으로 시작하지 않습니다.

메인 창 크기는 기본·고급 모드별로 기억합니다. 크기를 조절한 뒤 약 0.5초 후 저장하며, 모드를 바꾸거나 프로그램을 다시 실행하면 복원합니다. 최소화·최대화 중인 크기는 일반 창 크기를 덮어쓰지 않으며, 복원할 때 현재 화면의 작업 영역에 맞춥니다.

단축키 안내 바로 아래의 **기본값으로 초기화**는 확인 후 모든 선택 설정과 모드별 창 크기를 기본값으로 되돌립니다. 기본 모드에서는 별도 설정 창에, 고급 모드에서는 본문에 표시됩니다. 진행 중인 번역과 선택 영역은 해제하며, API 키·다운로드 모델·로그와 업데이트 확인 기록은 유지합니다.

| Python을 찾지 못함 | Python 설치와 PATH 등록을 확인한 뒤 터미널을 다시 열기 |
| 패키지 설치 실패 | CMD의 오류, 인터넷 연결, Python과 지정 패키지의 호환 여부 확인 |
| GPU 사용 불가 | CPU 모드를 선택하거나 NVIDIA GPU·드라이버·CUDA용 PyTorch 확인. CTD GPU 오류는 setup.bat으로 ONNX Runtime GPU 설치도 확인 |
| 시작 시 준비가 오래 걸림 | 하단 진행바와 OCR 모델 다운로드·로딩 상태 확인 |
| API 인증·한도 오류 | 선택한 서비스의 키와 한도를 확인하고 올바른 키 입력 |
| 모델 목록 조회 실패 | 서버 주소·키와 `/models` 지원 여부 확인 |
| 호환 API 번역 실패 | 선택한 모델의 Chat Completions 지원 여부와 서버 상태 확인 |
| API 설정 파일 손상 | 키를 다시 입력하면 자동 저장·적용. 저장 시 원본은 백업 폴더에 보관 |
| 글자를 놓침 | 선택 영역을 좁히고 감지 해상도·말풍선 하나 옵션 변경 |
| ESET 보호 브라우저가 캡처되지 않음 | ESET 개요 → 브라우저 화면 보호 → 일시 중지 → 적용 후 다시 번역. 사용 후 보호 다시 켜기 ([공식 안내](https://help.eset.com/essp/19/en-US/idh_config_bsp.html)) |
| 캡처 오류·번역 위치 어긋남 | 화면 이동을 멈추고 다시 번역. 필요하면 번역기 창을 영역 밖으로 옮기고 영역 재선택 |
| 단축키 동작 안 함 | 등록 오류, 다른 앱과의 충돌, 영역 선택·설정 적용 중인지 확인 |
| 로그 파일을 열 수 없음 | 파일 권한·잠금 상태 확인. 파일 기록 없이 실행되며 창에 안내 표시 |

Windows 캡처 보호가 확인되면 경고 창을 표시하고 해당 번역 작업을 중단합니다. 전체 캡처 결과가 거의 균일한 검은색이면 화면 보호 가능성을 안내합니다. 검은 원문도 같은 안내가 나올 수 있으며, 보안 프로그램이 보호 상태를 공개하지 않고 다른 화면을 반환하는 경우에는 감지하지 못할 수 있습니다.

자세한 오류는 상태창과 `logs/manga-live-YYYY-MM-DD.log`에서 확인하세요. 자동 번역이 오류로 멈췄다면 원인을 해결한 뒤 **번역 시작**으로 재개합니다.

## 지원 범위

- Windows 전용이며 원문은 **일본어·영어**, 번역 결과는 **한국어**입니다.
- OCR·번역 정확도와 스크롤 추적은 글씨체, 배경, 화면 이동, 하드웨어, API 응답에 영향을 받습니다.
- 말풍선 단위로 처리하므로 장면 전체의 문맥이나 인물의 말투를 충분히 반영하지 못할 수 있습니다.
- 취소는 결과 반영을 중단합니다. 이미 보낸 API 요청이나 실행 중인 모델 연산이 즉시 중단되는 것은 아닙니다.
- 원본 이미지 편집, 번역 이미지 저장, 만화 파일 일괄 변환은 지원하지 않습니다.
